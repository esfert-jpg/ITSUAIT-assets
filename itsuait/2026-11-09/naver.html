오픈AI(OpenAI)가 이미지 2.6 활용 가이드를 공개했어요. 정확한 이미지를 만들려면 프롬프트에 용도와 구도, 스타일을 구체적으로 적고, 편집할 때는 수정할 부분과 보존할 부분을 명확하게 나눠야 한다는 내용이에요.


▶ 플레어냐 선버스트냐, 어느 모델을 고를까

이미지 2.6은 두 가지 모델로 나뉜다고 했어요. 속도를 우선하는 경량 모델이 '플레어'이고, 세밀한 표현이 필요할 때 쓰는 기본 모델이 '선버스트'예요. 둘 다 이미지 생성, 편집, 투명 배경을 지원해요.


응답 속도가 중요한 작업이라면 플레어부터 시작하는 게 좋아요. 복잡한 구도나 높은 편집 정확도, 풍부한 세부 묘사가 필요하면 선버스트를 선택해요. 같은 프롬프트로 플레어를 먼저 테스트한 다음 결과와 응답 시간을 비교해서 선버스트가 필요한지 판단할 수 있어요.


▶ 프롬프트에 용도·구도·스타일을 구분해서 적기

'커피 광고 이미지를 만들어줘' 같은 단순한 지시보다 자세한 프롬프트가 훨씬 효과적이에요. 예를 들면 '신제품 아이스커피 광고용 사진을 만들어줘. 투명한 유리잔을 중앙에 배치하고 밝은 자연광과 흰색 배경을 사용해 줘. 제품명은 상단에 넣고 다른 문구는 추가하지 마' 처럼 주제와 구도, 스타일, 반드시 지켜야 할 조건을 항목별로 구분해서 작성하는 거예요.


복잡한 작업이면 장면, 피사체, 세부 사항, 제약 조건을 더 세밀하게 나눌 수 있어요. 다만 프롬프트를 무조건 길게 적을 필요는 없어요. 중요한 건 요구사항을 명확하게 전달하는 거고, 모든 요소를 이미 지정했다면 불필요한 설명은 피하는 게 낫다고 했어요.


▶ 글자를 넣을 때와 기존 이미지 편집할 때 팁

텍스트가 들어가는 이미지를 만들 땐 정확한 문구를 따옴표로 표시하고 위치, 글꼴, 등장 횟수까지 지정해요. '포스터 상단 중앙에 "AI FUTURE 2026"이라는 문구를 굵은 글씨로 정확히 한 번만 넣고 다른 글자는 넣지 마' 같은 식이에요. 특히 작은 글자나 복잡한 문구는 생성 후 철자와 가독성을 직접 확인해야 해요.


기존 이미지를 수정할 때는 변경할 대상뿐만 아니라 유지할 요소를 구체적으로 지정하는 게 중요해요. 예를 들어 인물의 옷을 바꾸려면 '얼굴과 표정, 헤어스타일, 자세, 배경과 조명은 그대로 유지하고 옷만 검은색 재킷으로 바꿔줘' 라고 요청하는 거예요. 여러 번 편집할 때는 한꺼번에 많이 바꾸기보다 한 가지씩 수정하고 결과를 확인하는 방법이 효과적이에요.


▶ 투명 이미지로 수정 위치를 직접 표시하기

원본 사진과 수정 대상을 표시한 투명 이미지를 함께 올리면 특정 부분만 바꾸도록 정확하게 지시할 수 있어요. 주방 사진에서 화병에 빨간 원을 그리고 '화병의 색상만 파란색으로 바꾸면서 다른 사물과 조명은 유지해' 라고 요청하면, 모델이 위치 표시용 원도 함께 제거한 결과를 돌려줘요.


복잡도와 화질은 서로 다른 역할을 해요. 복잡도는 생성 전에 구도와 요소 배치를 얼마나 깊이 계획할지를 결정하고, 화질은 질감이나 작은 글씨 같은 시각적 세부 묘사에 영향을 줘요. 복잡도를 높이면 항상 결과가 좋아지는 건 아니라고 했어요. 구도가 이미 상세하게 지정됐거나 특정 부분만 수정할 때는 낮은 복잡도가 더 적합할 수 있어요.


▶ API 요청 시 설정할 파라미터들

개발자가 API를 쓸 때는 모델을 'gpt-image-2.6-flare' 또는 'gpt-image-2.6-sunburst' 중 선택해요. quality는 auto, low, medium, high, xhigh, max 중에서 고르는데, 질감이나 작은 글씨 같은 시각적 세부 묘사를 조절해요. complexity는 low, medium, high 중 선택하며, 생성 전 구도와 요소 배치를 얼마나 계획할지 결정해요.


size는 auto로 설정하거나 1024x1024(정사각형), 1536x1024(가로), 1024x1536(세로) 등 지원하는 크기로 설정해요. background는 auto, opaque, transparent 중에 고르는데, 투명 PNG나 WebP 사용 시 알파 채널을 확인하고 SVG 출력도 투명성을 지원해요. output_format은 png, jpeg, webp, svg, gif 중 선택하며, JPEG와 WebP만 output_compression을 지원한다고 했어요.


▶ GIF 애니메이션과 SVG 로고 제작 방법

GIF 애니메이션을 만들 때는 동작의 시작과 끝을 연결하도록 지시하는 게 중요해요. 캐릭터가 등불을 들어 올렸다가 처음 자세로 돌아오는 장면을 예로 들면서, 카메라의 움직임 여부도 지정하도록 권장했어요. 처음과 마지막 자세가 자연스럽게 이어지면 반복 재생되는 애니메이션을 만드는 데 도움이 돼요.


로고를 제작할 때는 크기를 바꿔도 품질이 유지되는 SVG 형식을 활용할 수 있어요. SVG는 벡터 형식이므로 다양한 크기로 확대·축소해도 선명함이 그대로 유지되는 장점이 있어요. 일반 챗GPT 화면에서는 일부 모델 선택과 고급 설정을 직접 조정할 수 없지만, 용도를 구체적으로 설명하고 정확한 문구를 지정하며 바꿀 부분과 유지할 부분을 구분하는 기본 원칙은 바로 활용할 수 있어요.
