③ 본문 (태그 포함)

오픈AI가 29일 데브데이 2026에서 '닷츠(Dots)'를 공개했어요. 사용자가 기기를 꺼 있어도 백그라운드에서 스스로 일을 지속하는 기업용 자율 에이전트예요. 메타의 소비자용 에이전트 '뮤즈'와 달리 B2B 워크플로우를 겨냥했어요.


▶ 닷츠가 하는 일, 기존 챗GPT와 뭐가 다른가

기존 챗GPT는 질문에 답하는 데 멈췄어요. 닷츠는 업무 자체를 맡겨 놓으면 필요한 단계를 스스로 찾아 완료해요. 사용자가 하나하나 지시할 필요가 없어요.


예를 들어 회의 자료에 최신 수치를 반영하고, 웹사이트 디자인 변경을 적용한 뒤 배포까지 맡길 수 있어요. 일정이 겹치면 회의 이동 가능 여부를 확인하고 필요한 자료를 미리 준비해요.


개발 업무도 가능해요. 오래된 API를 새로운 방식으로 바꾸라고 하면 코드 전체에서 해당 API를 찾아 영향을 분석하고, 수정하고, 테스트한 뒤 검토할 수 있는 결과물을 만들어요.


▶ 격리된 클라우드 컴퓨터가 24시간 일해요

닷츠마다 독립된 가상 클라우드 컴퓨터와 전용 브라우저가 할당돼요. 사용자의 스마트폰이나 컴퓨터가 꺼져 있어도 계속 일을 진행해요.


웹사이트를 직접 열어 작업하거나 코드를 작성하고 테스트할 수 있어요. 4000개가 넘는 오픈AI 플러그인 생태계의 앱들과도 연동돼요.


슬랙, 마이크로소프트 팀즈, 문자 메시지 등 기존 업무 채널에서 단일한 대화 맥락을 유지해요. 문자 메시지 기능은 프로 사용자 대기자 명단으로 우선 제공돼요.


▶ 기업용 '전문 닷츠'로 조직 단위 도입도 가능해요

개별 에이전트에 전용 ID, 시스템 로그인 자격 증명, 사내 데이터베이스 접근 권한을 부여할 수 있어요. 조달, 청구서 처리, 이메일 마케팅, 고객 지원, 계약서 검토 등 전담 직원이 맡던 일을 에이전트에 위임해요.


보안도 강화됐어요. 저장된 비밀번호를 모델에 직접 노출하지 않아요. 선제적 리서치 시에는 읽기 전용 모드로만 작동해요. 계정 변경이나 결제 같은 민감한 업무는 반드시 인간 승인을 거쳐야 해요.


마이크로소프트의 기업 보안 제어 체계 '에이전트 365'와 엔터프라이즈 ID 관리 시스템 통합도 예정돼 있어요. 사내 입력 데이터와 백그라운드 작업 내역은 모델 학습에 절대 사용되지 않아요.


▶ 가격 정보와 이용 방법

닷츠는 챗GPT 프로, 비즈니스 프리미엘 구독자에게 기본 1개가 포함돼 제공돼요. 새로운 '챗GPT 프로 500(월 500달러)' 플랜은 초당 최대 300토큰의 응답 속도를 내는 울트라패스트 티어가 탑재됐어요.


고부하 백그라운드 작업으로 추가 토큰 소모가 발생하면 종량제로 과금돼요. 기업용 엔터프라이즈 고객 정식 출시와 일반 개발자 API 공개는 4분기부터 대기자 명단을 거쳐 차례로 진행될 예정이에요.


인간 팀원과 닷츠가 협업할 수 있는 '챗GPT 스페이스'와 문서 도구 '페이지스'도 함께 추가됐어요. 팀 단위 프로젝트에서 사람과 에이전트가 같은 공간에서 문서를 실시간으로 공동 편집할 수 있어요.
