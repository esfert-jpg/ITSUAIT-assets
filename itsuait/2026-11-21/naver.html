③ 본문 (태그 포함)

오픈AI(OpenAI)가 GPT-6.2 아스트라와 솔 모델을 비롯한 일부 모델에서 처리 완료 시간 목표를 정하면 API 요금을 최대 40%까지 낮출 수 있는 옵션을 내놓았어요. 빠른 응답이 필요 없고 비용 절감이 중요한 경우에 적합한 새로운 과금 방식입니다.


▶ API 완료 시간 옵션, 어떤 모델과 요금제에 적용되나

처리 완료 시간 지정 옵션은 GPT-6.2 아스트라, GPT-6.2 솔, GPT-6.1 테라, GPT-6 루나 모델에서 공개 베타로 운영되고 있어요. 즉시 결과가 필요한 작업에는 기존의 표준 요금제가 유지됩니다.


이 기능은 대용량 데이터 처리나 긴 시간이 걸리는 AI 작업에서 비용 부담을 줄이고 싶은 개발자나 기업을 대상으로 합니다. 단기간 내 응답 대신 비용 효율 위주 작업에 맞춰졌어요.


▶ 완료 시간 설정에 따른 요금 절감 효과는

API 사용 시 2시간 또는 8시간 내 완료 목표를 정할 수 있어요. 2시간 내 작업 완료 목표를 선택하면 표준 요금 대비 약 30% 할인되며, 8시간 내 완료 목표를 잡으면 최대 40% 비용 절감 효과가 있습니다.


응답 속도를 늦추는 대신 요금 부담이 줄어 대량 문서 분석이나 긴 시간에 걸친 AI 에이전트 작업에 특히 유리해요. 다단계 처리 과정도 조건을 만족하면 동일한 할인 혜택을 줍니다.


▶ 이전 플렉스 요금제와 차이점은 무엇인가

예전엔 응답이 느려지는 대신 낮은 요금을 제공하는 '플렉스' 방식을 썼는데, GPT-6.2 아스트라와 솔 모델부터는 플렉스 요금 지원을 중단했어요.


이 대신 완료 시간 기반 할인 옵션만 제공하면서 최신 모델을 더 저렴하게 쓸 수 있도록 바뀌었어요. 빠른 응답이 꼭 필요하지 않은 작업에 완성 시간 설정 방식을 권장합니다.


▶ 모델별 특징과 활용 포인트는

GPT-6.2 아스트라는 전문적이고 복잡한 작업에 강점이 있어요. 문서 작성, 스프레드시트, 프런트엔드 개발, 코드 작성에서 품질을 높이고 AI 고유의 흔적을 줄였어요.


또 과학 분야 성능도 개선돼 관련 벤치마크에서 높은 점수를 냈고 단가도 낮췄습니다. 반면 GPT-6.2 솔 모델은 일상 작업을 빠르고 효과적으로 처리하며 자연스러운 글쓰기를 지원해 기본 모델 역할을 하고 있어요.


▶ API 완료 시간 옵션 이용 방법과 유의점

개발자는 Responses API 백그라운드 모드에서 2시간이나 8시간 완료 목표 시간을 지정할 수 있어요. 작업이 목표 시간보다 빨리 끝나면 결과를 즉시 받을 수 있습니다.


예를 들어, 보고서를 다음 날까지 제출해야 하는 대용량 문서 분석 같은 작업에 8시간 목표 설정을 하면 40% 저렴한 요금으로 쓸 수 있어요. 그러나 빠른 응답이 필요한 경우에는 이 옵션을 쓰지 않는 게 좋고, 표준 요금제가 적용됩니다.
