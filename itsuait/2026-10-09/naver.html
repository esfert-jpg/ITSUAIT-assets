구글 클라우드가 제미나이(Gemini)를 단순 질답 AI에서 업무 자동화 에이전트로 바꿨어요. 지금은 기업 고객부터 사용할 수 있으며, 구글 워크스페이스·마이크로소프트 365·슬랙 같은 업무용 앱과 연결돼요.


▶ 질답형과 에이전트형, 뭐가 달라졌나

기존 제미나이는 사용자 질문에 답하거나 텍스트·이미지·코드를 만드는 대화형 AI였어요. 새 에이전트는 한 단계 더 나아가 목표까지 받을 수 있어요. 사용자가 '이것을 완성해 달라'고 말하면, 에이전트가 스스로 계획을 짜고 필요한 도구를 불러와 회사 내부 시스템과 연결한 뒤 결과물을 완성해 줘요.


일의 규모가 크면 에이전트는 자기 업무를 작은 조각으로 나눠 하위 에이전트에게 넘겨요. 모든 과정이 한 화면에서 일어나고, 사용자는 태스크 인박스에서 에이전트가 어떻게 생각하고 판단했는지 추적할 수 있어요.


▶ 지금 쓸 수 있는 기업, 어떤 앱과 연결되나

에이전트는 제미나이 엔터프라이즈를 쓰는 기업이면 바로 사용 가능해요. 구글에 따르면 포춘 100대 기업 중 약 90%가 이미 제미나이 엔터프라이즈를 도입했어요. 초기 테스터로는 온(On, 스포츠 신발 브랜드)·쇼피파이·페이팔이 참여했어요.


에이전트는 iOS·안드로이드 모바일, 윈도·맥OS 데스크톱, 명령줄 인터페이스에서 쓸 수 있어요. 구글 워크스페이스(Gmail·드라이브·독스·슬라이드·시트·채팅·캘린더)·마이크로소프트 365·슬랙·지라·컨플루언스·깃·빅쿼리·데이터브릭스·포스트그레스·스노우플레이크·서비스나우 등과 연결돼요. 향후 일반 사용자에게도 공개될 예정이지만, 구글은 먼저 기업의 보안·확장성·성능을 확인한 뒤 확대하기로 했어요.


▶ 에이전트가 처리할 수 있는 업무는

에이전트는 한 번의 지시로 여러 일을 처리해요. 지식 업무와 질문 응답, 이미지·영상 같은 미디어 콘텐츠 생성, 코드 작성 및 실행, 파일·폴더 첨부가 포함된 요청 처리, 프로젝트 관리(파일과 기술이 결합된) 같은 업무를 혼자서 끝낼 수 있어요.


기업 내부 시스템과 연결되면 더 복잡한 일도 가능해요. 사용자가 에이전트가 회사 안팎 네트워크의 모델 컨텍스트 프로토콜(MCP) 서버와 보안 연결을 하도록 설정할 수 있거든요. 에이전트는 사용자가 접근할 수 없는 데이터는 못 봐요. 에이전트의 권한이 사용자 권한과 같기 때문이에요.


▶ 일을 맡기고 모니터링하는 방법

에이전트에게 일을 시키는 방법은 여러 가지예요. 태그로 호출하거나, 이메일을 보내거나, 자료를 공유하거나, 그룹 채팅에 초대하는 식으로 임무를 줄 수 있어요. 에이전트는 별도의 워크스페이스 계정과 이메일 주소를 가지고 있어요.


에이전트가 팀을 이루고 일할 때 팀 구성·팀원의 시간대·누가 승인권을 갖는지·각자의 일정을 파악하고 업무를 처리해요. 사용자는 태스크 인박스에서 에이전트의 생각 과정, 위임한 작업, 불러온 기술과 코드, 진행 상황을 모두 볼 수 있어요. 작업이 끝나면 감사 추적이 개인 이름이 아닌 에이전트 명의로 남아요.


▶ AI 모델 선택과 비용 관리 기능

에이전트는 기본 설정에서 작업에 맞는 AI 모델을 자동으로 고르는데, 사용자가 직접 지정할 수도 있어요. 처음에는 앤트로픽(Anthropic)의 클로드(Claude) 모델을 지원하며, 구글은 오픈소스 모델과 다른 비공개 모델도 추가할 계획이에요.


기업이 비용을 관리하도록 구글은 세 가지 기능을 제공해요. 여러 AI 모델을 섞어 써면서 비용 효율을 따지는 멀티모델 오케스트레이션, 작업 특성에 맞춰 가장 싼 경로로 처리하는 스마트 라우팅, 정한 예산을 넘지 않도록 실시간 제한하는 지출 상한선 기능이에요. 이 기능들을 조합하면 기업이 에이전트 도입 비용을 유연하게 관리할 수 있어요.


▶ 보안과 접근 제어는 어떻게

구글은 에이전트가 기업 정책과 보안 요구사항을 지키도록 설계했어요. ID·정책 관리, 권한 부여·접근 제어, 보안 샌드박싱, 네트워크 게이트웨이 기능이 들어가 있어요.


에이전트가 기업 내부나 외부 네트워크의 MCP 서버와 연결할 때도 보안 연결을 유지해요. 에이전트는 사용자가 갖는 권한과 기업 정책의 범위 안에서만 작동하므로, 사용자가 어떤 데이터나 시스템에 접근할 수 없으면 에이전트도 마찬가지예요.
