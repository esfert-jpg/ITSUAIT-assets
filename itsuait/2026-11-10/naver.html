▶ 성능 평가에서 1위 차지한 페이블 5.2

아티피셜 애널리시스의 성능 평가 지수에서 페이블 5.2는 65점을 기록해 1위에 올랐어요. 구글 제미나이 4 카본은 60점, 클로드 오퍼스 5.5는 59점이에요. 페이블 5.2의 세 가지 추론 설정이 상위 3개를 모두 차지했어요.


실제 작업 능력을 보면 더 두드러져요. 코딩 능력 평가인 프론티어코드 2.0에서 페이블 5.2는 49.1%를 기록했는데, 이전 버전인 페이블 5.1은 32.4%였어요. 지식 업무를 평가하는 리모트 레이버 인덱스에서는 17.9%에서 41.3%로 크게 뛰어올랐어요. 전문 지식과 추론을 평가하는 항목에서 80%를 기록해 제미나이 4 카본의 69%를 앞섰어요.


▶ API 가격 20% 내리고 처리 속도는 30% 빨라진 구조

입력 토큰 100만개당 8달러, 출력 토큰 100만개당 40달러예요. 이전 버전보다 각각 20% 낮춘 가격이에요. 빠른 처리가 필요하면 선택 가능한 빠른 모드도 있어요. 빠른 모드는 입력 토큰 100만개당 16달러, 출력 토큰 100만개당 80달러이고 토큰 생성 속도를 최대 2.5배 높여요.


페이블 5.2는 이전 버전보다 출력을 최대 30% 빠르게 생성해요. 실제 작업 비용까지 따져보면 더 효율적이에요. 프론티어코드 평가에서 페이블 5.2는 45.3% 성능을 작업당 평균 6.72달러로 달성했어요. 같은 평가에서 오퍼스 5.5는 45.5% 성능을 작업당 12.82달러로 달성했어요. 페이블 5.2가 거의 같은 성능을 절반 수준의 비용으로 해내는 거죠.


▶ 페이블 5.2와 미소스 5.2, 누가 쓸 수 있나

페이블 5.2는 클로드 코드 유료 구독자와 개발자라면 누구나 쓸 수 있어요. 클로드 코드, API, AWS, 구글 클라우드, 마이크로소프트 애저를 통해 제공돼요. 미소스 5.2는 사이버 보안과 생명과학 분야 전문 작업용이에요. 이 모델에 접근하려면 앤트로픽의 라이프 사이언스와 사이버 검증 프로그램에 신청해 승인을 받아야 해요.


두 모델은 같은 기반 모델이지만 안전장치가 다르게 구성돼 있어요. 페이블 5.2는 일반 사용자와 개발자 대상이라 사이버 보안과 생물학 분야의 안전장치를 기본으로 담았어요. 미소스 5.2는 해당 분야 전문 작업을 위해 일부 제한을 완화했고, 검증을 거친 기관과 기업에만 제공해요.


▶ 미소스 5.2의 보안 역량과 실제 사용 사례

미소스 5.2는 사이버 보안과 생명과학 분야에 최적화돼 있어요. 가장 강력한 분열 공격 방어를 적용했고, 사이버 보안과 생물학 분야의 안전장치를 페이블 5.1 수준으로 유지하면서 불필요한 차단을 줄였어요. 소프트웨어 보안 취약점 평가에서 89.6%를 기록해 실용적 능력을 증명했어요.


페이블 5.2의 개발팀들은 이미 성능 개선을 확인했어요. 버셀은 다른 모델로 몇 주 동안 진행하던 개발 프로젝트를 페이블 5.2로 며칠 만에 마무리했어요. 앤트로픽 자체 실험에서는 1000개 이상의 하위 에이전트를 지휘해 8일 만에 운영체제 시제품을 만들고, 파이썬 서비스를 러스트로 이전해 시작 속도를 약 26배 높였으며, 전자기기까지 설계·제작했어요.
