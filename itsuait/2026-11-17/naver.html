③ 본문 (태그 포함)

알리바바가 새 AI 모델 큐원4-맥스를 11월 16일 정식 출시했어요. 작업당 비용을 전작 대비 67% 줄이면서도 코딩 성능에서는 클로드 오퍼스 5.5를 앞섰어요.


▶ 비용은 얼마나 내렸나요

작업당 평균 비용이 큰 폭으로 떨어졌어요. 전작 큐원3.8-맥스는 10.02달러였는데, 큐원4-맥스는 3.27달러가 됐어요. 약 67%를 절감한 거예요. 중국 경쟁사 키미 K3.1 프로의 작업당 비용 3.68달러보다도 더 저렴해요.


토큰 사용량도 함께 줄었어요. 같은 작업을 처리하는 데 필요한 토큰이 추론 강도에 따라 24~35% 감소했어요. 알리바바가 자체 개발한 평가인 워크360에서는 평균 작업 비용이 4.43달러에서 1.67달러로 약 62% 내려갔어요.


▶ 코딩 작업 성능은 어떤가요

소프트웨어 개발 성능이 특히 돋보여요. 딥SWE 1.1이라는 코딩 평가에서 75.7점을 받았는데, 클로드 오퍼스 5.5의 74.2점을 앞서갔어요. 웹 개발 능력을 평가하는 코드 아레나에서도 6위에 올랐어요.


실제 업무를 수행하는 에이전트 평가에서는 더 큰 성장을 보였어요. 전작 큐원3.8-맥스는 39위였는데, 큐원4-맥스는 14위로 크게 올라갔어요. 다만 터미널 환경에서 소프트웨어 개발 작업을 하는 터미널벤치 4.0에서는 48.5%의 성능을 보여 키미 K3.1 프로의 67.2%보다는 아직 뒤져 있어요.


▶ 아키텍처와 연산 효율의 개선점

모델 구조에 큰 변화가 있었어요. 매개변수는 2조4000억 개로 유지했지만, 실제 활성화되는 매개변수를 950억 개에서 710억 개로 25% 줄였어요. 같은 크기의 모델에서 더 효율적으로 작동하도록 설계한 거예요.


게이티드 델타넷, 큐원 희소 어텐션, 게이티드 레지듀얼 같은 새로운 기술이 적용됐어요. 긴 문맥을 처리할 때 필요한 계산량을 줄이고 모델 내부 정보 전달을 개선했어요. 추가로 3280억 개의 N-그램 임베딩 매개변수를 사용해 연속된 토큰의 패턴을 더 잘 학습하도록 했어요.


▶ 전문 분야 활용과 실제 사례

금융, 법률, 의료, 제조 같은 여러 분야에서 성능이 검증됐어요. 721개 세부 전문 분야를 대상으로 한 워크360 평가에서 52.69점을 기록했는데, 전작의 47.74점을 넘어섰어요.


실제 산업 현장에서의 활용 사례도 있어요. 자동차 부품 제조 실험에서는 AI가 설계와 가공 과정을 수정해 수작업 프로그래밍 시간을 475분에서 24분으로 줄였어요. 반도체 냉각 소재 연구에서는 AI 에이전트를 48시간 동안 실행하며 분자 설계와 합성, 실험을 반복해 새로운 물질 후보를 찾아냈어요. 알츠하이머병 연구에서도 새로운 후보 분자 24개를 설계했어요.


▶ 안전성 강화와 공개 계획

보안 측면을 더 신경 썼어요. 소프트웨어 개발 학습에 보안 검사를 추가했고, 소프트웨어 취약점을 찾고 고치는 데 필요한 보안 지식은 학습하도록 했어요. 동시에 해킹 공격 능력을 키우는 자료는 의도적으로 학습에서 빼놨어요.


오픈소스 공개 계획도 있어요. 큐원4-맥스 자체는 오픈소스로 공개되지 않고 API 형태로 접근해야 해요. 하지만 큐원4 제품군 중 작은 모델들은 곧 가중치를 공개할 계획이에요. 블룸버그에 따르면 큐원 시리즈는 지금까지 세계에서 가장 많이 내려받은 오픈 웨이트 모델 제품군이에요.
