앤트로픽(Anthropic)의 클로드 쉽은 깃허브 저장소에서 코드를 검토하고 수정하며 자동 승인까지 하는 AI 도구예요. 기존 코드 리뷰에 더해 PR 전 과정을 AI가 처리해 개발팀 작업을 빠르게 만듭니다.


▶ 클로드 쉽 기능과 자동화 범위

클로드 쉽은 클로드 팀과 엔터프라이즈 요금제 사용자를 위해 나왔어요. 이 도구는 AI 에이전트가 풀리퀘스트 검토에서부터 코드 수정, 최종 승인 결정까지 전 과정을 자동으로 수행합니다. 덕분에 개발자가 일일이 코드를 관리하지 않아도 되고 병합 속도가 빨라져요.


기존 클로드 코드 리뷰 기능에 이번에 PR 스튜어드와 클로드 승인 에이전트가 새로 추가됐어요. PR 스튜어드는 CI 실패나 머지 충돌, 코드 피드백을 보고 코드를 자동으로 고치고, 수정 사항을 푸시할 때마다 댓글로 알려줘요. 개발자가 중단 지시도 할 수 있어요.


▶ 자동 승인과 정책 설정 방식

클로드 승인 에이전트는 팀의 승인 정책 파일을 기준으로 자동 승인을 결정해요. 단순한 변경은 자동 승인 처리하고 복잡한 경우에는 사람이 검토해서 승인하게 돼요. 승인 정책은 자연어로 작성되며, 팀마다 조건과 적용 범위를 직접 설정할 수 있어요.


팀은 검토 깊이도 빠른 검토, 표준, 깊은 리뷰 중 선택 가능합니다. 승인 기준과 월간 지불 한도 역시 팀이 직접 조절할 수 있어 사용 관리를 손쉽게 할 수 있어요.


▶ 누가, 어떤 요금제로 클로드 쉽을 쓸 수 있나

클로드 쉽은 현재 클로드 팀과 엔터프라이즈 요금제 사용 조직만 이용할 수 있어요. 대상 조직은 깃허브 저장소와 연동해 사용하며, 코드 리뷰 기능은 정식으로 공개되어 누구나 쓸 수 있습니다.


새롭게 추가된 PR 스튜어드와 클로드 승인 기능은 아직 베타 버전이라 제한된 접근 권한이 있어요. 엔터프라이즈 조직은 2027년 1월 15일까지 클로드 쉽 크레딧 1만 달러를 청구할 수 있고, 청구 후 30일 동안 쓸 수 있습니다.


▶ 클로드 쉽 사용 시 주의사항과 작동 과정

자동 승인은 팀 승인 정책 조건을 충족해야 하고, 복잡한 상황에서는 사람이 최종 검토합니다. 베타 상태이므로 운영 전에는 관찰 모드로 설정해 결과를 충분히 확인하는 것이 권장됩니다.


PR 스튜어드는 푸시할 때마다 변경한 내용을 댓글로 자세히 알려줘서 개발자가 어떤 부분이 수정되었는지 쉽게 검토할 수 있어요. 필요하면 수정된 부분을 롤백할 수도 있습니다. 또 팀은 사용 시 월간 지불 한도를 정해 비용 관리도 할 수 있어요.
