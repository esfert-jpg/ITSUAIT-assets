③ 본문 (태그 포함)

DXC 테크놀로지가 앤트로픽(Anthropic)의 AI 모델 클로드 미토스(Claude Mythos)를 활용한 새로운 관리형 코드 보안 서비스 프론티어 코드 어슈어런스(Frontier Code Assurance)를 내놓았어요. 이 서비스는 기업들의 핵심 애플리케이션 보안 취약점을 자동으로 검증하고 개선하는 데 도움을 줘요.


▶ DXC 프론티어 코드 어슈어런스의 특징과 차별점

프론티어 코드 어슈어런스는 기존 보안 스캐너가 종종 놓치는 코드 취약점을 AI 모델 클로드 미토스가 찾아내는 점에서 차별화돼요. 이 과정에서 DXC의 보안 전문가가 탐지된 문제를 검증하고 기업에 미치는 영향을 평가해 우선순위를 부여해요. 기업마다 필요한 패치 작업 우선순위를 명확히 해서 단계별 개선 계획을 제공해요.


이전에는 AI가 빠르게 문제를 찾지만 이를 개선하는 조치 단계에서 시간이 지체되는 경우가 있었어요. 이 서비스는 그런 병목 현상을 해소하기 위해 설계돼서 취약점 탐지부터 개선까지 한 번에 지원하는 원스톱 서비스 형태로 제공돼요. 40여 개국에서 운영하는 12개 보안관제센터와 수천 명 전문가 역량이 함께 지원을 보장해요.


▶ 서비스 사용 대상과 도입 방법

DXC 프론티어 코드 어슈어런스는 핵심 업무용 소프트웨어 보안을 강화하려는 기업에 적합해요. 클로드 파트너 네트워크의 글로벌 프리미어 파트너인 DXC는 앤트로픽 AI와 자사의 사이버 보안 전문 역량을 모두 활용할 수 있게 했어요. 기업들은 이 서비스를 통해 AI 기반 취약점 발견에서부터 전문가 검증, 신속한 개선 작업까지 관리할 수 있어요.


도입 절차는 기업이 보호할 애플리케이션을 선정하는 것으로 시작해요. AI가 코드를 분석해 가능성 있는 취약점을 자동으로 탐지하면, 전문가가 이를 확인하고 비즈니스 영향도에 따라 우선순위를 결정해요. 그 뒤 단계별 개선 로드맵과 근거 자료가 제공돼 기업은 적절한 패치와 보완 작업을 진행할 수 있어요.


▶ 사용 시 주의사항과 서비스 한계

프론티어 코드 어슈어런스는 AI와 전문가 검증 과정을 결합해 탐지 신뢰도를 높였지만 모든 취약점을 완벽히 찾아내진 못해요. AI가 일부 결함을 놓칠 수도 있기 때문에 보안 위험 관리를 보완하는 한 요소로 활용해야 해요.


기업은 이 서비스를 적용할 때 보호 대상 애플리케이션과 사업 중요도를 고려해 우선순위를 정하는 것이 효율적이에요. 또 DXC가 제공하는 전문가 검증과 개선 로드맵을 꼭 활용해야 하고, 필요하면 기존 보안관리 체계 내 다른 도구나 솔루션과 병행 사용하는 것도 가능해요.


▶ 기존 보안 스캐너와 프론티어 코드 어슈어런스 비교

기존 보안 스캐너는 자동 분석 위주라 일부 취약점을 놓칠 가능성이 있다는 한계가 있어요. 반면 프론티어 코드 어슈어런스는 AI 클로드 미토스로 탐색 범위를 넓히고, 보안 전문가가 직접 검증과 영향 분석을 더해요. 이렇게 해서 취약점 개선 우선순위와 단계별 로드맵을 제공하는 관리형 서비스 형태로 운영돼요.


또한 기존 도구는 글로벌 지원에 한계가 있지만, DXC는 40여 개 국가에서 12개 보안관제센터와 수천 명 전문가를 통해 광범위한 지원을 가능하게 했어요. 이 점이 서비스 경쟁력을 높여요.
