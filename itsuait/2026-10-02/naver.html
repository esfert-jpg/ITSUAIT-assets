클라우드플레어가 데이터 플랫폼을 'Basin'으로 새로 브랜드화하면서 정식 출시했어요. 서버리스 방식으로 클러스터 관리 없이 데이터를 저장하고 처리할 수 있어요.


▶ Basin이 뭐가 바뀐 건가

기존 클라우드플레어 Pipelines, R2 Data Catalog, R2 SQL이 각각 Basin Pipelines, Basin Catalog, Basin SQL로 이름이 바뀌었어요. 베타 상태에서 정식 서비스로 전환된 거예요.


클라우드플레어 CTO 대니 크넥트는 "클러스터를 관리할 필요가 없고, 불필요한 데이터 이동도 없으며, 오픈 스탠다드를 사용해 데이터 통제권을 유지할 수 있다"고 설명했어요.


▶ 이그레스 요금 없다는 게 뭔지

아마존 S3, 구글 클라우드 스토리지, 애저 블롭 스토리지는 데이터를 다른 지역으로 옮길 때 요금을 매겨요. Basin은 이 요금이 없어요. R2 스토리지에서 데이터를 꺼내고 다른 지역으로 옮기는 데 비용이 안 든다는 뜻이에요.


Apache Iceberg 표준을 써서 클라우드 벤더에 종속되지 않아요. DuckDB, PyIceberg, Snowflake, Spark, StarRocks, Trino 같은 외부 도구로도 데이터를 쿼리할 수 있어요.


▶ 요금이 정말 안 드나

R2에서 직접 데이터를 꺼내면 요금이 안 들어요. Workers API, S3 API, r2.dev 도메인을 통한 이그레스는 무료예요.


하지만 Basin Pipelines로 스트리밍 데이터를 R2에 실어 나를 때는 요금을 매겨요. 클라우드플레어는 이를 '싱크(egress)' 요금이라고 부르고 있어요. 다른 측정 서비스를 R2 버킷에 연결하면 그 서비스 회사가 별도로 요금을 청구할 수도 있어요.


▶ 누가 쓰면 좋을까

데이터를 여러 클라우드와 지역에 걸쳐 저장하면서 비용을 줄이고 싶은 회사들이 관심을 가질 거예요. 데이터 카탈로그로 데이터를 정리하고, 자신이 선택한 분석 도구로 쿼리할 수 있으니까요.


클라우드플레어는 Bobsled 같은 업체가 "여러 클라우드 지역에서 데이터 상품을 만들면서 이그레스 요금이 없어서 비용을 대폭 줄일 수 있다"고 평가하고 있어요.
