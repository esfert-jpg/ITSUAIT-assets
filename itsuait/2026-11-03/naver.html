클라우드에 저장된 대형언어모델 API 키가 도용돼 하루에 10만 달러를 넘는 요금 폭탄이 터지는 공격이 늘어나고 있어요. 구글 맨디언트는 2026년 한 해 금융·소매·기술·운송업체들이 이 'LLMJacking' 공격을 당했다고 보고했어요.


▶ API 키 도용으로 몇 시간 만에 거액 요금 발생

LLMJacking은 범죄자가 회사의 API 키를 탈취한 뒤 그 키로 대량의 API 요청을 날려서 클라우드 서비스 요금을 부풀리는 공격이에요. 맨디언트가 대응한 사건들을 보면 하루에 10만 달러가 넘는 청구서가 나왔고, 일부 조직은 침해를 발견하고 접근을 차단하기 전까지 누적으로 100만 달러에 달하는 요금이 쌓였어요.


암호화폐 채굴 공격과 달리 이 공격은 몇 시간 안에 극심한 손해를 입혀요. 한 사례에서는 아주 짧은 시간 내에 대량의 API 요청이 기록됐고, 다른 사건에서도 제한된 시간 내에 엄청난 규모의 LLM API 호출이 실행됐어요. 사용량이 천천히 늘어나는 게 아니라 갑자기 폭증하므로 청구서를 받고 나서야 알아차리는 경우가 많아요.


▶ 공격자들의 분업화된 수익 모델

흥미로운 점은 API 키를 빼내는 범죄자와 그걸 팔아서 돈을 버는 범죄자가 다르다는 거예요. 후자를 '리미서'라고 부르는데, 이들은 탈취한 LLM 접근 권한을 불법적으로 모아서 지하 마켓에 재판매하는 서비스를 운영해요. 맨디언트는 두 개의 서로 다른 범죄 세력이 협력해 기업 LLM 인프라를 침해하고 수익화하는 사례를 확인했어요.


UNC6993으로 추적되는 범죄 집단은 LLM API 키에 불법 접근한 뒤 추가 키를 생성하고 피해자 클라우드 프로젝트 내에서 서비스를 활성화해 10만 달러 규모의 청구서를 만들었어요. 또 다른 경우에는 피해자 계정을 '종량제 계약'에 강제로 가입시킨 뒤, 수명이 짧은 서비스 계정을 만들었다 삭제하는 방식으로 사용량 제한을 우회했어요.


▶ 도용 키로 운영하는 불법 LLM 서비스

'제트나이트'라는 토큰 라우팅 서비스는 도용된 제3자 API 키를 이용해 대규모 LLM API 호출을 실행하고 있어요. 월간 구독료를 저가로 제공하면서 최신 모델에 접근할 수 있게 하는데, 정상적인 시장 가격보다 훨씬 싸요. 구글 위협 인텔리전스 그룹은 이렇게 저가로 서비스할 수 있는 이유가 도용 키에 의존하기 때문이라고 판단해요.


제트나이트는 공개 텔레그램 채널에서 여러 번 장애를 인정했는데, 구글 분석가들은 이것이 피해 기업이 침해를 발견하고 자신의 키를 취소하면서 생기는 일이라고 지적해요. 도용된 키가 계속 무효화되면서 불법 서비스가 먹통이 되는 거죠.


▶ 공격자가 API 키를 빼내는 방법

공격자들은 단순한 수준의 자원 탈취에서 벗어나 백엔드 모델 자원을 직접 노리고 있어요. 공개적으로 노출된 LLM 엔드포인트를 찾거나 유효한 API 키를 획득하는 데 집중하죠. 2026년 중반 맨디언트가 대응한 한 사건에서는 UNC6993이 잘못 설정된 서비스 계정 키를 통해 클라우드 인스턴스를 침해하고, 그 접근으로 모델 API에 추가 권한을 부여했어요.


공격자는 LLM 사용자 그룹에 참여하는 애플리케이션 포털로 위장한 세션 하이재킹 페이지를 설치하기도 해요. 이 페이지는 사용자를 정상적인 LLM 서비스 웹사이트로 유도한 뒤, 활성 접근 토큰을 담은 원본 JSON 페이로드를 붙여넣게 속여요. 그러면 백엔드 API로 전송되면서 비밀번호와 다중인증 제어를 우회할 수 있어요.


▶ 기업이 당장 해야 할 보안 조치

구글은 LLMJacking이 암호화폐 채굴 같은 다른 자원 탈취 유형보다 우선순위가 높아질 거라고 예측해요. 방어를 위해서는 신원 및 접근 관리와 공급망 보안을 최우선으로 삼아야 해요. 중앙집중식 보안 관리 플랫폼을 도입해 API 키와 보안 정보를 정기적으로 교체하는 게 필수예요.


모든 사용자와 서비스에 최소 접근 권한을 적용하면 한 개의 키나 계정이 도용돼도 피해 범위를 제한할 수 있어요. API 키가 깃허브 같은 공개 저장소에 실수로 올라가는 걸 막기 위한 모니터링도 중요해요. 암호화폐 채굴은 장기간에 걸쳐 천천히 자원을 소비하지만, LLMJacking은 몇 시간 안에 거액을 빨아가므로 조기 탐지와 신속한 차단이 생사를 가르는 문제예요.
